# Future-State Platform Vision — Direct Lending Connection

**Horizon:** 12–36 months of **incremental** evolution (not rewrite). Aligned with existing **blocks**, **Convex**, **multi-tenant**, and **CLI deploy** culture.

---

## 1. North star experience

**“One operational record home”** — Every file is a **fast**, **calm**, **dense** workspace where:

- **Economics, stage, chosen lender, next task** are always obvious.  
- **Deep work** (scenario, documents, messaging) is **one gesture** away, never **three** navigations.  
- **Mobile** brokers run the **same** workflows as desk brokers with **snap/sheet** ergonomics.

---

## 2. Architecture pillars (future)

| Pillar | Today | Future |
|--------|-------|--------|
| **Modular blocks** | Registry + per-file layout | **Phase-aware layouts** + org templates + A/B layout presets |
| **Record inspectors** | Task/lender drawers | **Unified** side-sheet framework + contact/doc |
| **Motion** | Tokens + Vaul | **Three motion classes**, full reduced-motion audit |
| **Color** | Classic + SaaS + tints | **Semantic MD3-aligned** roles + optional **harmonized** tenant palettes |
| **Data truth** | `fileSharedState` | Richer **audit** and **undo** for money fields; clearer override copy |
| **Automation** | Workflows + webhooks | **Visible** automation log per file; user-facing “playbooks” |
| **Scale** | Solid for early growth | **Virtualized** hubs, paged APIs, **regional** latency awareness |

---

## 3. Differentiated CRM + fintech story

- **Lender-centric** workflows (attach, scenario, term export) **first-class**, not bolt-ons.  
- **Referral + commission** clarity for brokerage teams.  
- **Portal** that feels as **polished** as Mercury’s transaction feed for **clients**.

---

## 4. Organizational maturity

| Area | Vision |
|------|--------|
| **RBAC** | Surface **permission-denied** states as **actionable** (request access) |
| **White-label** | Per-org **theme packs** from one seed color |
| **Integrations** | Connector catalog UX rivaling Zapier **without** leaving file context |

---

## 5. Research backlog (product)

1. Time-to-first-lender-attach (median).  
2. File switch frequency per session.  
3. Mobile vs desktop **task completion** rate.  
4. Support tickets tagged “where is contact?” / “wrong number.”

---

## 6. What not to do

- **Greenfield** second app shell.  
- **Big-bang** redesign without migration paths for `fileDrawerLayout`.  
- **Breaking** scroll contracts without Playwright mobile coverage.

---

## 7. Sequencing (suggested)

1. **Semantic trust tokens** + side-sheet unification.  
2. **File workspace** orchestration split + perf.  
3. **Hub** scale + mobile card view.  
4. **Contact** model UX finish line.  
5. **Automation** transparency.  
6. **Portal** trust parity.
