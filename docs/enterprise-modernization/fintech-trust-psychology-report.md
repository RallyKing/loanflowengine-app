# Fintech Trust + Psychology Report

**Lens:** Operator **confidence**, **perceived stability**, and **professionalism** — analogous to Ramp/Mercury calm, Stripe precision, institutional banking sobriety.

---

## 1. Emotional confidence

| Signal | Strength | Weakness |
|--------|----------|----------|
| **Single economic truth** (`fileSharedState`) | High — rare in CRM | Overrides confuse if copy jargon-heavy |
| **Stable scroll** (workspace sheet) | High | Regressions would feel “broken app” |
| **Modular blocks** | Medium-high | Too many expanded → overwhelming |

**Prototype-feeling triggers:** Layout jump on load; inconsistent spinners; mismatched currency formats.

---

## 2. Financial professionalism

| Element | Assessment |
|---------|------------|
| **Typography** | Brand serif — distinctive; ensure **tabular nums** in tables |
| **Color** | Forest/gold and SaaS blue — professional if **semantic** errors stay red |
| **Density** | Broker-grade acceptable; avoid “consumer pastel” in money paths |

---

## 3. Stability perception

| Risk | Mitigation |
|------|------------|
| **Chrome motion** | Transform/opacity only on scroll paths |
| **Snap sheet** | No jump between snap points; respect reduced motion |
| **Hydration** flash | Skeleton-first on file |

---

## 4. Motion anxiety

| Pattern | Anxiety level | Guidance |
|---------|---------------|----------|
| **Compact chrome** | Low if predictable | Document behavior |
| **Drawer slide** | Low–medium | Consistent duration |
| **Celebratory** animation on money | **High** — avoid | Use subtle confirmation |

---

## 5. Color psychology

| Issue | Fix |
|-------|-----|
| **Gold near warning** | Semantic warning token distinct from `--brand-accent` |
| **Stage pills** low contrast | Admin theme audit |
| **Destructive** too colorful | Muted red container + clear label |

---

## 6. Destructive-action fear

| Flow | Trust requirement |
|------|-------------------|
| **Delete file** | Typed confirm + list consequences (tasks? portal?) |
| **Clear lenders** | Same |
| **Archive** | Explain rediscovery path |

---

## 7. Loading-state confidence

| Bar | Pattern |
|-----|---------|
| **File detail** | Structured skeleton |
| **Convex slow** | Indeterminate progress + “still working” copy |
| **Upload** | Percent + cancel |

---

## 8. Error messaging trust

| Rule |
|------|
| User-facing: **what happened** + **what to do** |
| No raw stack in portal |
| Support **reference id** on repeated failures |

---

## 9. Data integrity confidence

| Mechanism |
|-----------|
| **FieldSyncIndicator** plain language |
| **Activity** for mutations |
| **Undo** where promised |

---

## 10. Stage + override clarity

| Risk | Copy pattern |
|------|--------------|
| Stage doesn’t match economics | **Warning** chip when deal type vs stage odd |
| Override silent | “You changed only this block’s view…” |

---

## 11. Auditability

| Gap | Opportunity |
|-----|-------------|
| **Automation** invisible | Activity + delivery log |
| **Admin** template changes | Audit trail surfacing |

---

## 12. Identity signaling

| Surface | Expectation |
|---------|-------------|
| **Portal** | Org logo, name, lock icon, URL trust |
| **Email** from product | Branded, DKIM story (ops, not UX doc) |

---

## 13. Portal confidence breakdowns

| Failure mode | Psychology hit |
|--------------|----------------|
| Generic error | “Is this phishing?” |
| Half-loaded branding | Unprofessional |
| No **scope** copy | “Can they see everything?” |

---

## 14. Mobile trust breakdowns

| Issue |
|-------|
| **Mis-tap** on destructive |
| **Keyboard** hides “Save” |
| **Snap** too small to read amounts |

---

## 15. Feels consumer vs enterprise

| Consumer pattern | Enterprise replacement |
|------------------|------------------------|
| Playful empty illos | Operational CTA + metrics |
| Gamification | **None** unless onboarding checklist (already cautious) |
| Loud success confetti | Toast + activity entry |

---

## 16. Items that reduce operator confidence (watchlist)

1. Conflicting contact models.  
2. Number mismatch between blocks.  
3. Silent automation.  
4. **Search** wrong result.  
5. Portal/client visual mismatch.
